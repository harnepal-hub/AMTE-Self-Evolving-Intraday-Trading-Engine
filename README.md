# AMTE — Self-Evolving Intraday Trading Engine

A dedicated research and engineering project for developing AMTE's intraday trading engine.

## Scope

V1 focuses exclusively on **intraday trading**. Interday/swing functionality will be developed as a separate module after the intraday engine is stable.

## Development principles

- Modular architecture
- Reproducible backtesting
- Explicit risk management
- No look-ahead bias
- Separation of data, signals, execution, and evaluation
- Versioned strategies and model experiments
- Paper trading before live execution

## Initial roadmap

1. Project foundation
2. Market-data ingestion and normalization
3. Feature/indicator pipeline
4. Intraday signal engine
5. Risk and position management
6. Backtesting engine
7. Performance analytics
8. Paper-trading interface
9. Broker integration
10. Self-evaluation and controlled strategy evolution

> This repository is a development project, not financial advice or a guarantee of trading performance.
