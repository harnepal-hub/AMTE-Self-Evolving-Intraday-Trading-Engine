Signal: price wicks beyond the prior lookback high/low, then the candle closes back inside. Signal is evaluated on a closed candle; entry is at the next candle open.
Both versions use the same signal timestamps, sizing rule, stop/target percentages, fee and slippage assumptions. Inverse flips LONG↔SHORT and places stop/target for the reversed direction. If stop and target both touch in one candle, stop is counted first.
This is a historical simulation, not proof of profitability. Candle-only data cannot reproduce exact order-book fills or funding. Check multiple coins and timeframes before drawing conclusions.
